# aie-pt-2-class-2

# Desarrollando interfaces con componentes visuales comunes usando Tailwind CSS

## 1. Dominando la Arquitectura de Diseño Web para Desarrolladores Full-Stack

### Objetivo
Entender cómo se organiza una interfaz web desde la experiencia de usuario, la estructura visual y la elección de patrones de diseño.

### Contenidos
- Qué es la arquitectura de diseño web.
- Por qué el diseño es la columna vertebral de la experiencia del usuario.
- Cómo reconocer patrones de diseño para tomar decisiones informadas.
- Relación entre rol del desarrollador e interacción de usuarios con productos digitales.

### Ideas clave
- Elegir entre barra lateral o barra superior según el tipo de producto afecta la usabilidad.
- El desarrollador no solo codifica: también influye en cómo se percibe e interactúa con la interfaz.
- Aprender a detectar estructura visual ayuda a crear sistemas más claros y consistentes.

### Actividad
Analizar ejemplos de interfaces y justificar qué patrón de diseño conviene en cada caso.

## 2. Reconocimiento y Estructura de Componentes Web

### Objetivo
Aprender a identificar componentes comunes y estructurarlos correctamente con HTML semántico.

### Contenidos
- Tipos de componentes: tarjeta, modal, dropdown, toggle, table y select.
- Cómo detectar componentes dentro de un diseño.
- Cómo estructurarlos semánticamente usando HTML.
- Patrones de navegación, diagramas de contenido y diseño atómico.

### Ideas clave
- Los componentes son la base de interfaces escalables y reutilizables.
- El HTML semántico mejora accesibilidad y mantenimiento.
- El diseño atómico permite construir sistemas de UI más consistentes.

### Actividad
Identificar componentes en una interfaz y descomponerla en bloques reutilizables.

## 3. Diseño Web Responsivo

### Objetivo
Diseñar interfaces que se adapten correctamente a móvil, tablet y escritorio usando enfoque mobile first.

### Contenidos
- Diseño responsivo vs. adaptativo vs. de ancho fijo.
- Mobile first por defecto.
- Tamaños fijos vs. tamaños relativos.
- Media queries y puntos de interrupción.
- Layout flexible e imágenes adaptables.

### Ideas clave
- El diseño responsivo mejora accesibilidad y experiencia en todos los dispositivos.
- El enfoque mobile first obliga a priorizar el contenido esencial.
- Los breakpoints permiten adaptar la interfaz sin romper la jerarquía visual.

### Actividad
Construir una cuadrícula de tarjetas responsiva con 640px y 1024px como puntos de interrupción, mostrando una columna en móvil, dos en tablet y tres en escritorio.

## 4. Tailwind CSS

### Objetivo
Usar Tailwind como herramienta para construir interfaces rápidas, consistentes y responsivas.

### Contenidos
- Clases utilitarias.
- Modificadores responsivos.
- Mobile first por defecto.
- Aplicación práctica en layouts y componentes.

### Ideas clave
- Tailwind acelera el desarrollo visual.
- La composición de clases facilita mantener consistencia.
- Los modificadores responsivos simplifican el trabajo con breakpoints.

### Actividad
Recrear una interfaz simple aplicando utilidades de Tailwind y variantes responsive.

## 5. Accesibilidad y ARIA en componentes

### Objetivo
Comprender la importancia de la accesibilidad en componentes interactivos.

### Contenidos
- Uso de ARIA en modales.
- Buenas prácticas en componentes interactivos.
- Relación entre accesibilidad y experiencia de usuario.

### Ideas clave
- La accesibilidad debe considerarse desde el diseño.
- ARIA ayuda a describir mejor la funcionalidad de componentes complejos.
- Un componente accesible mejora el producto para todos los usuarios.

### Actividad
Revisar un modal e identificar qué atributos ARIA necesita para ser accesible.
